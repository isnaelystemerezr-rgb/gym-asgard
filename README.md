# gym-asgard
Gym Asgard

He creado este sitio web de un gimnasio con temática nórdica como Práctica Integradora de la asignatura Programación Web.

Descripción:
Mi sitio está compuesto por 5 vistas enlazadas entre sí, con diseño responsivo, modo claro/oscuro y formularios con validación HTML5.

Vistas:
- index.html  →  Inicio
- sobre.html  →  Sobre nosotros
- servicios.html  →  Servicios
- contacto.html  →  Contacto
- login.html  →  Iniciar sesión

Tecnologías que usé:
- HTML5 semántico
- CSS3 (Flexbox, Grid, variables, transiciones y animaciones)
- Diseño responsivo y modo claro/oscuro
